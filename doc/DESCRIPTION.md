Publishing platform for personal Markdown blogs. No trackers, no heavy
styling, server-side rendering, fast pages. Engine of bearblog.dev, packaged
for self-hosting.

### Features

- Markdown editor, live preview
- Every registered user gets a blog on a subdomain (`myblog.example.org`) or a
  custom domain
- Landing page, signup, dashboard (posts, pages, tags, feeds)
- RSS/Atom/JSON feeds, sitemap, basic analytics (hashed IPs, GeoIP country)
- One blog owner account made at install from the chosen YunoHost admin; rest
  self-register

Upstream is the hosted SaaS source, not built for self-hosting. SaaS-only parts
(payments page, S3 media uploads) inert here — see admin doc.
